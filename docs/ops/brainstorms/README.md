# Brainstorm outcomes — CINs

Kết quả session `/cins:brainstorm` (hoặc skill `cins-brainstorming`) lưu tại đây.

## Quy ước tên file

```
YYYY-MM-DD-<slug-ngan>.md
```

Ví dụ: `2026-07-14-gallery-rank.md`

## Không lưu

- Secret, API key, mật khẩu, token
- Dữ liệu PII user thật ngoài những gì đã public trong docs nội bộ

## Sau khi chốt

- Quyết định bền → thêm mục vào `docs/CINS_DECISIONS.md` (sau khi user xác nhận) **hoặc** file ngắn trong `docs/ops/decisions/`
- Preference / procedure bền → Graphiti `[CINS]` nếu MCP available
